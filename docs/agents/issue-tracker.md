# Issue Tracker

Issues for this project live in [GitHub Issues](https://github.com/SeaOfLee/days_counter/issues).

Engineering skills that interact with issues (`to-tickets`, `to-spec`, etc.) use the `gh` CLI to create, read, and update issues. They assume:

- Issues are created in the GitHub repo's Issues tab
- Standard GitHub labels are used for triage
- Issue titles and bodies are Markdown
- Closing an issue means resolving it in code or marking it as wontfix

PRs are **not** treated as a request surface by default. If you want PRs to appear in the triage queue alongside issues, edit this file to set `prs_as_requests: true`.
